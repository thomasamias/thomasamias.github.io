# Segurança e privacidade

Este repositório deve permanecer público somente com conteúdo anonimizado.

## Não publicar

- URLs internas de SharePoint, Forms, Power Apps, Power Automate, Power BI ou Genesys.
- E-mails, nomes, matrículas, cargos, IDs internos ou dados pessoais.
- Tokens, conexões, client secrets, headers, bodies de API e strings de conexão.
- Dados reais de chamados, SLAs, filas, URAs, relatórios ou indicadores.
- Arquivos Excel reais com fórmulas, caminhos, regras internas ou tabelas operacionais.
- Prints contendo dados corporativos visíveis.

## Publicar com segurança

- Dados sintéticos.
- Diagramas reconstruídos.
- Prints borrados ou refeitos como mockup.
- SQL alvo sem dados reais.
- Pseudofluxos em vez de exportações de automações.
- Documentação pública sem nomes de pessoas, sites internos ou informações sensíveis.
