# Power Apps: tratativa operacional

## Telas públicas recomendadas

- Painel de chamados.
- Consulta e filtros.
- Detalhe do chamado.
- Atualização de status.
- Registro de resposta.
- Envio de e-mail.
- Logs de ações.

## Eventos de log recomendados

| Evento | Quando registrar |
|---|---|
| AppOpen | Abertura do aplicativo |
| Search | Pesquisa de chamado |
| Filter | Aplicação de filtros |
| ViewTicket | Visualização de detalhe |
| UpdateStatus | Alteração de status |
| SendEmail | Envio de resposta |
| Error | Falha de ação |

## Publicação segura

Use prints com dados fictícios ou completamente borrados. Nunca publique nomes, e-mails, matrículas, números reais de chamados ou links internos.
